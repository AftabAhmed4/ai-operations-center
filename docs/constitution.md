# **Project Name**

Autonomous AI Operations Center for Watch Retail Business. \- NexusForge

---

# **Project Vision**

Build a mobile-first AI-powered operational intelligence system for a watch retail business operating in Karachi, Lahore, and Islamabad.

The system combines:

* lightweight operational workflows  
* autonomous AI agents  
* operational analytics  
* action execution simulation  
* live workflow tracing

The core purpose of the application is NOT to build a full ERP.

The core purpose is to demonstrate:

Input → Understanding → Reasoning → Decision → Approval → Execution → State Change

The application should feel like:  
“AI operating a real business system autonomously.”

---

# **Hackathon Objective**

The system must demonstrate:

* unstructured content understanding  
* business insight extraction  
* operational impact analysis  
* autonomous action generation  
* action execution simulation  
* live workflow tracing  
* system state changes after execution

Google ADK orchestration must be central to the application architecture.

# **AI Data Processing Rules**

IMPORTANT:

Large datasets must NOT be directly sent to agents.

Use:

* pandas  
* numpy

for:

* aggregation  
* filtering  
* anomaly detection  
* trend analysis  
* statistical processing

Only processed structured insights should be sent to agents.

Example:

{  
"city": "Lahore",  
"sales\_decline\_percentage": 24,  
"inventory\_risk": true,  
"top\_declining\_products": \[  
"Rolex Black",  
"Casio Silver"  
\]  
}

LLMs are reasoning engines, not spreadsheet engines.

# **Approval System**

AI must NOT directly execute important actions.

Approval flow:

AI proposes action  
↓  
Frontend approval modal  
↓  
User approves or rejects  
↓  
Execution continues

Examples:

* pricing updates  
* campaign generation  
* inventory redistribution

---

# **Execution Simulation Requirements**

The system must simulate real operational actions.

Simulation examples:

* database update  
* campaign creation

* inventory updates  
* pricing updates
