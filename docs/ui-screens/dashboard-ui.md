# ChronosForge — Mobile Dashboard UI Prompt

Design a premium mobile dashboard UI for **ChronosForge**, an AI-powered retail operations platform.

## Style
- Clean enterprise SaaS UI
- Modern, minimal, spacious
- Inspired by Linear, Stripe, and Notion AI
- Light theme only
- High-end AI business OS feel

## Colors
- Primary: `#2563EB`
- Background: `#F8FAFC`
- Text: `#0F172A`
- Success: `#16A34A`
- Warning: `#EA580C`
- Danger: `#DC2626`
- Border: `#E2E8F0`

## Layout

### Header
- Greeting: **"Good Morning, Muhammad"**
- Subtitle: **"AI Operational Overview"**
- Notification icon

### Metric Cards (Horizontal Scroll)
Include:
- Revenue
- Orders Today
- Inventory Alerts
- Active Campaigns

Each card should contain:
- Icon
- Main number
- Trend %
- Mini sparkline chart

### Analytics
- Clean sales trend chart
- Regional performance section
- Low Stock Products
- High Demand Products

### Recent AI Actions
Timeline showing last 4–5 AI actions.

### Bottom Navigation
Tabs:
- Dashboard
- Operations
- Products
- Sales
- Reports

## Requirements
- Mobile-first layout
- Smooth spacing and rounded cards
- Soft shadows and subtle borders
- Premium typography
- Professional, polished, futuristic SaaS design
